# 重生避难所 (Rebirth Shelter)

> 末日废土 · 文字挂机生存 · 天灾轮回 Roguelike

一款**纯前端、零构建、单机可玩**的末日生存挂机游戏。你操纵一名废土幸存者，在昼夜循环中探索、采集、制作装备、建设避难所，抵御一场场越来越强的天灾——死后带着"前世记忆"重生，一代代把文明从石斧推向量子时代。

**当前版本：v1.0.0**（正式版）｜ 详细开发史见 [docs/DEVLOG.md](docs/DEVLOG.md)

---

## ✨ 游戏特性

- **挂机友好**：每秒一个游戏时钟节拍，关掉浏览器离线结算照样推进（最多回溯 7 天），主角不会死
- **天灾轮回**：天灾按序列推进、提前预告类型；波次强度锚定装备代际曲线，永远"差一点点"逼你变强
- **双成长线**：外出探索（战力 vs 区域威胁）与守家建设（防御 vs 灾害强度）互相独立又彼此支撑
- **装备代际 ×1.8**：石制 → 铁器 → 机械 → 幽能 → 纳米 → …… → T24 量子时代，图纸 + 材质档双门槛
- **暗黑词缀**：装备按品质 roll 词条（搜集、远程压制、抗性、省粮……），Build 由词条组合决定
- **护符三插槽**：搜集效率叠加封顶 +300%，低代护符也能凑出高加成
- **无尽阶段**：12 个阶段后仍有新区域、新材料、新图纸，数值阶梯没有终点
- **多设备同档**：局域网内任何电脑打开主机地址即可接同一份存档（单写者裁决，不会互相覆盖）
- **天地灾异 6+ 种**：辐射尘 / 酸雨 / 寒潮 / 洪水 / 热浪 / 熵增……对应抗性词条与防灾设施各自减伤

## 🚀 快速开始

### Windows

1. 安装 [Node.js](https://nodejs.org)（≥ 18）
2. 双击 **`启动游戏.bat`**
3. 浏览器自动打开 `http://localhost:8787`

### macOS / Linux

```bash
node server.js
# 打开 http://localhost:8787
```

### 局域网多设备

主机启动服务后，同一局域网的其他电脑访问 `http://<主机IP>:8787`（或 `http://<主机名>:8787`），即可接同一份存档。

> 纯双击 `index.html` 也能玩（file:// 单机模式），但存档只存在浏览器里，推荐走服务。

## 💾 存档机制

| 层 | 说明 |
|---|---|
| **shelter.db**（SQLite） | 主存档，服务运行时实时写入（8 秒节流 + 关键节点强制落库） |
| **localStorage** | 服务断线时的兜底，恢复后自动比新迁回 |
| **导出/导入 JSON** | 游戏内手动备份，跨机器迁移 |
| **save_history 快照** | 数据库自动保留最近 60 份按天快照，可随时回滚 |

## 📁 目录结构

```
├── index.html          # 入口页面
├── server.js           # 零依赖本地服务（Node 内置 SQLite 存档）
├── 启动游戏.bat         # Windows 一键启动
├── css/  js/  assets/  # 纯前端资源（无构建、无外部依赖）
├── tools/              # 开发工具：冒烟测试、数值校验、地图诊断、崩溃复现
└── docs/DEVLOG.md      # 完整开发日志（v8.x 演进史）
```
