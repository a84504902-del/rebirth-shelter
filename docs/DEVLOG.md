# 重生避难所

一款**文字挂机 · 末世求生**游戏。重生回到灾变之初，只有一间破茅草屋和一处搜来的藏货，
靠每天出门搜集、搜刮废墟、加固避难所，一场场天灾熬过去。

现实 **1 小时 = 游戏 1 小时**，现实 1 天 = 游戏 1 天 —— 你的作息就是主角的作息。

---

## 启动方式

双击 **`启动游戏.bat`**（会自动打开浏览器进入 `http://localhost:8787/`）。
玩完直接关掉命令行窗口即可，进度已经写进数据库了。

> 需要本机装了 Node.js（`node -v` 能出版本号即可）。

## ★ 阶段体系（v7 新增，整个游戏的进度骨架）

三个阶段，物资 / 箱子 / 资源点 / 装备全部按阶段递进解锁。
**高阶层物品在低阶段"绝对不出现"——不是概率低，是没进池子。**

| | **阶段 1 · 求生期** | **阶段 2 · 工业期** | **阶段 3 · 能源期** |
|---|---|---|---|
| 时代 | 木器时代 | 铁器时代 | 机械电气时代 |
| 主力箱子 | 木箱 | 青铜箱 | 白银箱 |
| **推进条件** | 初始 | 渡过 **3 场天灾** + 工作台 **Lv.2** | 渡过 **5 场天灾** + 加固工事 **Lv.5** |
| 解锁物资 | 木/石/废金属/布料/兽皮/骨头/鳞片 | **铁矿/铜矿/煤** → 铁块/铜块/钢 | **硫磺/硝石/石油** → 火药/电池/燃料 |
| 解锁资源点 | 7 处（树林、碎石坡、超市…） | 铁矿洞 / 铜矿脉 / 露头煤层 | 硫磺坑 / 硝石床 / 废弃油田 |
| 工艺上限 | 石制装备 | 铁器与机械装备 | 火器与特化装备 |

**双轨推进的理由**：天灾是可预告的节奏（"再过 2 场灾就能进工业期"），建筑是明确目标（避免躺赢解锁）。两个一起，既有预告又有目标感。

阶段推进时会弹出全屏文本 + 解锁清单（`ages.js` 里的 `enter` / `unlock`）。

## ★ 地点产出：品类随危险度递进（v8 设计原则）

用户拍板："不是低级的产木头、高级的产水这种简单设定——**越高级的地方品类越丰富才是正确的**"。旧设定里"一地一种特产"，高级地（加油站威胁30 只有金属3.5/h、超市威胁55 只有粮水1.2/h）产出对不起危险度，低级地又各自报废。

新规则（`config.js` SPOTS）：

1. **基础三样（木/石/金属）哪都产**，且高级地更多——建材不再被单一地点卡脖子
2. **特色品是附加**：树林=木+兽皮、河湾=水、碎石坡=石、超市=粮水布、兽径=猎物
3. **危险溢价**：威胁越高，产量越厚（超市粮水 1.2→6/h，加油站金属 3.5→8/h）——"练战力 → 去险地 → 收获翻倍"的正循环成立
4. **矿点同理**：T2/T3 矿点也带基础产出（石/木/金属），阶段过滤下高阶矿在低阶段只出基础——阶段 1 的铁矿洞（威胁55）就是"高级采石场"，战力够早去早受益

| 地点 | 威胁 | 产出/小时（新） |
|---|---|---|
| 🏚️ 门口杂物堆 | 1 | 木2 金属1 石1 |
| 🌲 后山树林 | 1 | **木6** 石1 金属0.5 兽皮0.08 |
| 🏞️ 上游河湾 | 1 | **水5** 粮1 木2 |
| 🪨 碎石坡 | 2 | **石8** 木2 金属0.5 |
| ⛽ 旧加油站 | 30 | **金属8** 木4 石4 水2 |
| 🏪 废弃超市 | 55 | **粮6 水6** 布0.3 木3 石3 金属2 |
| 🦌 兽径 | 90 | **粮5 兽皮0.3** 木2 石2 金属2 |

## ★ 宝箱分级（四档 + 遗迹专属）

**箱子等级由"获取地点的危险度"决定**（照搬小说设定）：低危地点永远产木箱，高危才有好箱子。

| 箱子 | 来源 | 内容上限 |
|---|---|---|
| 🪵 木箱 | 杂物堆、树林、碎石坡、河湾 | T1 物资 |
| 🥉 青铜箱 | 加油站、超市、兽径、灾后废墟 | T2（铁块/铜块/煤） |
| 🥈 白银箱 | 高危地点、天灾奖励 | T3（硫磺/石油/工业蓝图） |
| 🥇 黄金箱 | 深处遗迹、高难天灾 | 全部 |
| 🔐 遗迹箱 | **探索遗迹专属** | **当前阶段 +1（唯一允许越级产出）** |

**实际产出 = min（箱子等级允许的阶层，当前阶段允许的阶层）** —— 所以第 1 阶段拿到青铜箱也能开，只是只能开出 T1 东西；**留着等进了工业期再开更划算**（界面会提示）。

> **危险溢价（v8.2）**：物资倍率每档 ×2 严格递进（木1 / 青铜2 / 白银4 / 黄金8 / 遗迹12）——含青铜与木箱的对比也一并修正。旧值白银只有青铜的 1.5 倍但获取难度 ×3（白银出在威胁 110~150 的硫磺坑/硝石床/油田），负体验。**白银箱及以上额外掉 T3 加工品**（铜线/火药/燃料/电池，每箱 1 种）——高档箱不只是"更多"，还"更不同"。

### 开箱规则（v7.10：物资筐必出 + 好东西叠加）

对齐小说设定（青铜箱 = 一批物资 + 厨房设计图 + 卫生间设计图，**物资和图纸同箱出现**）：

| 层 | 内容 | 概率 |
|---|---|---|
| **物资筐（必出）** | 口粮/水/肉/诱饵 + 木/石/废金属（每种数量随机）+ 1 种随机稀有材料 | **100%** |
| 装备 1 件 | 与物资不互斥，直接叠加 | 34% |
| 图纸（本阶段） | 叠加 | 木箱 2% / 青铜 3% / 白银 6% / 黄金 12% / 遗迹 25% |
| 越级图纸 | 叠加 | 见下表 |
| 彩蛋 / 兽皮保底 | 叠加，不再独占整箱 | — |

实测（`tools/once-chest-check.js`）：**平均每箱产出 8.0 种物品**。开箱不再是"单发赌分支"，每次打开都是"倒出一堆 + 说不定还有好货"。

### 越级惊喜（跨时代）

**硬规矩：图纸可以越级，成品装备不能越级。**

| 情况 | 概率 | 说明 |
|---|---|---|
| 同阶段极品装备（传说） | 0.8% | 惊喜，不破坏平衡 |
| **跨阶段图纸** | 木箱 0.3% / 青铜与白银 1.5% / 遗迹箱 15% | **长期钩子**——"现在做不了，但记住它" |
| 跨阶段成品装备 | **0%** | 会毁掉游戏（等于给私服的自己发毕业装） |

越级图纸会触发右下角金色浮层 + 日志永久标记。

## ★ 图纸掉落按阶段分层（v8.1）

用户拍板："**同一个难度出同一个难度的图纸才合理，偶尔出一个高一级的图纸是惊喜**"。旧逻辑全部图纸均匀随机，阶段 1 会掉"拉丝（T3 铜线）/冷库（储物 Lv4）/特化披风（火器）"这类远期废纸——渡过 3 场天灾拿不到一张能用的。

新规则（`bpTierOf` 给每张图纸标注阶段归属；`grantBlueprint` 分层抽选）：

- **85% 掉当前阶段的图纸**（阶段 1：绷带/兴奋剂/箱柜/槽位手册…）
- **15% 掉高一级的图纸**（惊喜钩子，为下一阶段做准备）
- **不再掉高两级**的废纸
- 当前阶段图纸集齐后自动滑向下一级（阶段 1 集齐 T1 → 开始稳定掉 T2，衔接工业期）
- 仓储告急/制作线占满的"优先给图纸"逻辑同样按阶段过滤
- 越级图纸机制（`BP_CROSS`，0.3%~15%）保留——那是极小概率的跨时代惊喜，与常规分层不冲突

> **图纸命名规则（v8.1）**：图纸名 = 它解锁的东西 + "图纸"——绷带图纸解锁绷带、铁块图纸解锁铁块提炼、冲锋枪图纸解锁冲锋枪，不再有"急救图纸解锁绷带"这种两个名字的困惑。旧档里的风味名（急救图纸/冶金图纸/铁器图纸（武器）等）在加载时自动改名，无损失。

**顺带修复两个 bug**：
1. 🎲 锈钥匙彩蛋直接 `S.chests.relic += 1` **绕过自动开箱**（箱子堆积偶发的真凶），且违反"遗迹箱仅探索遗迹专属"的设计——改为走 `addChest` 并按阶段给当前可用的好箱子
2. 图纸掉落测试自身未记录产出、且用 `||` 默认值踩了第无数次 falsy 坑——已修

## ★ 兽皮 / 绳索：一条死锁链的防线（重要设计教训）

曾经存在一条会**永久卡死玩家**的链条：

```
绳索 ← 兽皮 ← 捕猎陷阱 ← 绳索
                ↑
             诱饵 ← 生肉 ← 也是陷阱
```

只要玩家先造工作台（用掉新手礼包的绳索），就再也造不出陷阱 → 永远没兽皮 → 永远没绳索。

现在有**四条独立通道**获取兽皮，任何一条都能闭环：

| 通道 | 说明 |
|---|---|
| 捕猎陷阱 | 主力来源（诱饵是效率 ×2，不是开关；没诱饵也有 40% 效率） |
| **打赢野兽剥皮** | 野外遭遇获胜必掉兽皮 + 肉 |
| **后山树林采集** | 0.7 张/天，自然缓慢产出 |
| **硬保底** | 兽皮不够搓一根绳 + 没绳索 + 没陷阱 → 开箱或出门必定给 3 张 |

配套调整：陷阱成本 `rope:2 → 1`（留一根给工作台）；新手礼包直接送兽皮/肉/诱饵。

> **教训**：凡是出现"设施 A 需要材料 M、材料 M 又需要设施 A"的链条，必须为 M 准备**至少两条不依赖 A 的获取途径**，外加一条硬保底。这类死锁普通测试发现不了，只有专门测"最坏情况起步链路"才会暴露。

## ★ 首灾可生还性（v7.8 重平衡，核心设计底线）

早期版本有个致命问题：**主角活不过第一次天灾**。模拟发现，即使完美操作，3 天内最多也只能攒 ~120 石料，而工事 Lv1 要 160 石 + 120 木 → 永远造不出 → 防御恒为 0 → 首灾必输（损 30% 物资 + 板房降级）。

四条修正，让"准备了就能活"成为底线：

| 修正 | 改前 | 改后 | 理由 |
|---|---|---|---|
| **板房自带基础防御** | 0 | `houseLv × 20`（开局 Lv1 = 20） | 你睡在屋里不是露宿；保证即使只来得及造一级工事也不裸奔 |
| **工事 Lv1 成本** | 木120 + 石160 | 木60 + 石60 | 石料是瓶颈，必须降到 3 天可负担 |
| **碎石坡石料产出** | `stone:4` | `stone:6` | 配合上一条，让 60 石轻松凑齐 |
| **首灾强度（教学灾）** | 60 | 50 | 之后每场 +70 仍迅速变难，压力不丢 |

现在首灾（酸雨，第 3 天）：防御 = 茅草屋20 + 工事60 = **80 ≥ 50**，三条策略（探索优先 / 采石优先 / 纯采石）全部存活。第 2 场起强度 120+，必须继续升级 / 换更好的房子。

> **校正规则**：`def()` 的构成是 `避难所档位def + fortify×60 + traps×15 + 已装备护甲`（档位 def 查 `HOUSE_TIERS`）。任何改动若动了档位表或 `DIS_INTENSITY_BASE`，必须重跑 `tools/once-firstdis.js` 确认首灾仍可被生还，否则会无声地退回"首灾必输"。

## ★ 避难所材质升级链（v7.11，替代抽象 Lv1-10）

用户拍板："不要搞什么 1-10……第一个茅草屋、第二个木屋、第三个石屋，直接标明下一个是什么"。抽象等级对玩家没有叙事价值，每一步都应该叫得出名字。

| 档 | 名字 | 防御 | 升级材料（升入该档） | 一句话 |
|---|---|---|---|---|
| 1 | 🛖 茅草屋 | 20 | —（开局） | 几根木棍加一层草，勉强算个家 |
| 2 | 🏚️ 木屋 | 40 | 木材150 + 绳索2 | 真正的屋顶，雨点打不进来了 |
| 3 | 🏠 石屋 | 80 | 石料260 + 木材100 | 石墙又厚又凉，酸雨也拿它没办法 |
| 4 | 🏢 混凝土居所 | 150 | 铁块12 + 石料300 | 钢筋进混凝土，天灾开始讲道理 |
| 5 | 🏰 钢铁避难所 | 300 | 钢8 + 铁块24 | 它已经不是房子了，是堡垒 |
| 6 | 🗼 合金避难所 | 500 | 钢15 + 铜线8 + 电池4 | 电力驱动的新结构——已经有了城市的雏形 |

设计要点：
- **界面直接显示当前房子名 + 「升为「下一档」」按钮**，不再出现 Lv.x/10
- 每档一次"换房"，不走 COST_K 通式（花费是定值材料表，不是逐级 ×1.6）
- 档位同时是**其他设施的解锁门槛**：保温夹层/排水系统需木屋（2）、地下室需石屋（3）、密封舱门需混凝土（4）、农田需钢铁避难所（5）

### 防灾子系统（v8.5，对齐小说"每场天灾有专属建造命题"）

小说的核心玩法是**建设避难所本身来抗灾**——每场天灾都有对应的建造命题，而不是堆一个防御数字。落地为 5 个防灾设施（一次建成永久生效，与抗性装备**乘法叠加**）：

| 设施 | 解锁 | 抗性 | 建造材料 |
|---|---|---|---|
| 🧪 防酸涂层 | 茅草屋起 | 酸雨 -25% | 石80 + 布4 |
| 🧊 保温夹层 | 木屋 | 寒潮 -25% | 石120 + 布8 |
| 🌊 排水系统 | 木屋 | 洪水 -25% | 石150 + 木80 |
| 🕳️ 地下室 | 石屋（小说：地下室需石质结构） | 高温 -25% | 石250 + 铁块8 |
| 🚪 密封舱门 | 混凝土居所 | 辐射尘 -30% | 铁块12 + 钢4 |

装备抗性（-30%）与设施抗性（-25~30%）乘法叠加——**装备+设施齐备时对应天灾强度约打五折**，这就是"针对性的避难所升级"的意义。天灾报的"强度"栏会体现减免。
- 天灾打输会**跌回上一档**（"从石屋跌回了木屋"），损失变得具体可感
- 存档兼容：老档 `house 1~10` 自动收敛到 1~5（`Math.min(5, lv)`）

## ★ 游戏时钟（精确到分钟）

顶栏常驻 **🕐 14:32**，「⏳ 当前进行中」面板也显示当前时刻。所有倒计时都精确到分钟，并附带**现实时间换算**（游戏 1 小时 = 现实 20 分钟）：

```
下午 · 🏚️ 门口杂物堆                        🕐 14:32
[████████░░░░░░░]
下午 12:00 — 18:00　已过 40%　还剩 3 小时 28 分（现实约 1 小时 9 分）

🛠️ 制作线 2/3（出门也照做 ×1）
🪢 绳索　60%　还需 6 分（现实约 2 分）
```

- 新手期倒计时同样精确到分钟（`🛡️ 新手期结束倒计时　2 天 18 小时 42 分`）
- 工具函数在 `state.js`：`clockText()` / `fullClockText()` / `durText()` / `hourText()` / `realText()`

## ★ 制作耗时（按现实常识定价）

制作不再按"占一个时段"定价（那是旧设计的遗留），而是**按现实中合理的耗时**：

| 类别 | 例子 | 耗时 | 现实 |
|---|---|---|---|
| 简单加工 | 搓绳、做诱饵、绷带 | **15 分** | 5 分钟 |
| | 劈木板 | 30 分 | 10 分钟 |
| 需要熏/熬 | 熏肉 2 小时、熬兴奋剂 1 小时 | | |
| 熔炼 | 铁块 2 小时、炼钢 4 小时 | | |
| 装备 | 铁管长矛 1 小时、连发弩 3 小时 | | |
| 复杂装备 | **冲锋枪 6 小时**、防毒面具 4 小时 | | 保留等待感 |

好处：简单东西"点一下就出来"，限制来自**材料**而不是干等；复杂工艺仍有期待感。

## ★ 进度可视化（「⏳ 当前进行中」面板）

挂机游戏最容易让人心里没底："主角现在在干嘛？还要多久？"——主角面板上方常驻一块面板，两条进度条：

```
下午 · 🏚️ 门口杂物堆                     还剩 3.6h
[████████░░░░░░░░░░░░]  本时段进度 40%   12:00 — 18:00

🛠️ 制作：🪢 绳索  35%   还需 3.9 工时 · 抽空做 ×0.35
[███████░░░░░░░░░░░░░]
完成后得：🪢绳索×1

本时段已收获　🪵木材 ×31
```

- **第一条**：当前时段进度 + 剩余小时数（睡觉时显示"😴 睡觉回体力"）
- **第二条**：制作进度（有活计时才出现）、还需多少工时、完成后得到什么
- **本时段已收获**：实时累计，不用等日志

### 制作与外出：两条并行轨道（互不耽误）

**核心规则：制作不占用日程。** 主角出门采集/探索时，制作线照常推进，两条线各跑各的。

| 情况 | 速度 | 实测（绳索 6 工时） |
|---|---|---|
| 外出采集/探索（默认） | **×1 满速** | 7 小时做完 |
| 排「🛠️ 留守制作」时段 | ×2.5 加速 | 3 小时做完（快 2.3 倍） |

取舍保留（想快就得牺牲半天外出），但**不排也不打折**——不会"为了做东西而放弃整天采集"。
配置在 `config.js` 的 `CRAFT_IDLE_RATE` / `CRAFT_FOCUS_MUL`。

### 每日抽签：今日运势（v7.13）

采集产出原本是**纯固定值**（树林 = 5 木/小时，分毫不差）——挂机像打卡，没有起伏。改为**每个游戏日自动抽一签**，全天生效：

| 签 | 概率 | 采集收成 |
|---|---|---|
| 大吉 | 4% | **×2.5**（金色日志 + 顶栏高亮） |
| 中吉 | 12% | ×1.6 |
| 小吉 | 24% | ×1.2 |
| 平 | 40% | ×1.0 |
| 凶 | 15% | ×0.8 |
| 大凶 | 5% | ×0.6 |

- **期望 ×1.13（略正）**：抽签整体不亏、还有盼头；凶级温和，不给挂机玩家硬惩罚
- **只影响采集收成**（`sp.y` 产出）与**开箱好货**（v7.15）：箱子掉率本身不变，但**图纸概率 × 运势**（大吉木箱 2%→5%）、**装备品质线抬高**（大吉品质均值 1.37→1.64）、越级图纸概率也 ×运势（封顶 ×2）；材料数量不受运势影响，凶签无硬惩罚
- 跨天自动重抽，日志报签文（"🎲 第 X 天 · 今日运势【中吉】 采集收成 ×1.6"）；顶栏常驻 🎲 签名，吉绿凶红
- 命中随机性设计原则：**采集的随机与宝箱反着来**——宝箱是"数量固定给什么随机"，采集是"基础盘稳定、偶尔爆一下"

## ★ 天灾灾报与灾史（v7.16）

用户反馈"过了第一个天灾一点感觉也没有，没有公告、没有地方查过去的奖励"——天灾结算原来只有一行日志，仪式感为零。

- **灾后全屏公告**：每场天灾结算时弹出报告——结果（扛住了/失守）、防御 vs 强度对比、抗性装备是否立功、**奖励/损失逐项清点**（扛住：木材+230、石料+160、金属+150、青铜箱×1…；失守：物资 -30%、房子跌档、受伤）、下一场预告
- **灾史可查**：主角面板底部「📜 灾史」列出经历过的每场天灾（✅/❌、防御对比、奖励/损失摘要）
- **离线补公告**：离线期间过的天灾不弹横幅，但顶栏会出现「📋 XX灾报——点开查看」徽标，不会错过
- 存档字段：`S.disLog`（灾报数组）、`S.disUnread`（离线未读标记），老档自动兼容

### 制作线槽位：同时能做几种

限制制作的不是时间，而是**同时能开几条线**：

| 槽位 | 来源 |
|---|---|
| 2 条 | 开局自带 |
| 3 条 | 图纸「并行作业手册」 |
| 4 条 | 图纸「流水线图纸」 |
| 5 条 | 图纸「量产线图纸」（上限） |

- 每条线独立推进（可同时"熏肉 + 搓绳 + 炼铁"）
- **开工可选拨数量（v7.12）**：每个配方带 −/＋ 步进器（1~999），材料按数量一次性预扣，**做完一份立即入库**并自动连做下一份——不用一个一个点
- 同一配方不能重复开工；线占满时开工会提示需要哪张图纸
- **制作线占满时，开箱给图纸会优先给槽位图纸**（不让玩家卡住）
- 做错了可以「取消（退料）」，材料按剩余数量**全额**退回

制作面板顶部有槽位条（`▣▣□□□`），已占用/空闲/未解锁三种状态一目了然。

## ★ 生死系统（v7 新增）

### 三层保护

**第一层：离线免死（硬契约，不可协商）**

> **你不在场时，主角永远不会死。**

离线期间所有致命结算自动降级：死亡 → 重伤 + 损失本次收获 50%；濒死 → 受伤 + 丢部分补给。
*（页面切到后台标签页也算"不在场"，同样免死——见 `engine.js` 的 `tick()`）*

理由：挂机游戏的底线契约是"我离开时主角在变强"。一旦"回来发现人死了"，玩家就不敢再挂机——那恰好杀死了唯一的玩法。

**第二层：濒死阶梯（在线也不会猝死）**

```
健康 → 受伤（效率 -50%） → 重伤（-70%） → 濒死（24 游戏小时倒计时） → 才可能死
```

- 疗伤手段：白天排「😴 休息」降一级、用**绷带**降两级（濒死时的救命稻草）、夜间睡觉只能养好轻伤
- 进入濒死会红字警告 + 日程面板提示

**第三层：死亡 = 重生（扣题）**

游戏就叫《重生避难所》，所以**死亡不是失败，是第二幕**：

| 死亡时 | 处理 |
|---|---|
| **继承** | 全部图纸（知识不会忘）<br>部分设施等级（避难所保底茅草屋，其余随机保留约一半）<br>前世记忆（天灾预告提前 1 天/世） |
| **重置** | 物资归零、天数回到第 1 天、地图重新探索 |
| **加成** | 每重生的初始物资叠加（保证"这一世一定比上一世强"） |

死亡时弹"这一世回顾"：活了多少天、走到哪个阶段、开过多少箱子、去过哪些地方、死因。

### 储物箱：容量按图纸逐档解锁

**每一档容量都要一张图纸**（容量提升本身也是惊喜）：

| 档 | 名称 | 容量 | 需要图纸 | 附带 |
|---|---|---|---|---|
| 0 | 露天堆放 | 2500 | 开局自带 | — |
| 1 | 木箱柜 | 7000 | 木箱柜图纸 | 受灾损失 -8% |
| 2 | 分类货架 | 18000 | 分类货架图纸 | 受灾损失 -16% |
| 3 | 干燥储藏室 | 45000 | 干燥储藏室图纸 | **腐坏 ×0.7** |
| 4 | 冷藏库 | 120000 | 冷藏库图纸 | 腐坏 ×0.35 |
| 5 | 地下仓库 | 300000 | 地下仓库图纸 | 腐坏 ×0.1，受灾损失再降 20% |

> **★ 跳档凭证（v8.2）**：持有**目标档或更高档**的任一储物图纸即可升级——手里有冷藏库图纸（Lv4），Lv2/Lv3/Lv4 都能升，不再被"恰好缺下一档"卡死。图纸名与档名一一对应（冷藏库图纸 = 解锁冷藏库），一眼可辨。

> **新手大礼包直接送第一张「木箱柜图纸」+ 升级材料（木板×6、绳索×2）**——第一局就能把储物箱升到 Lv.1（2500 → 7000），既解决新手期爆仓，也顺手教会你"图纸 → 升级"这个机制。
>
> 数值依据（`node tools/balance-check.js` 可复算）：一箱材料约 72 容量 ≈ 1 天采集量；每天新增占用约 192；初始档位够撑 10 天左右，升到 Lv.1 后够撑一个多月。

### 爆仓了怎么办：分批丢弃

仓储超出容量时，库存面板会多出一块 **「🧹 谁最占地方」**——按容量占用排出前 5 项，每项带一排快捷按钮：

```
🪵 木材      占 183      [−1] [−10] [½] [全]
🪨 石料      占 65       [−1] [−10] [½] [全]
```

**四档丢弃粒度**：−1 / −10 / 丢一半 / 全丢（全丢带二次确认）。数量少的物品自动只显示 `−1` 和 `全`。**不会出现"只能整样扔掉"的情况。**


**溢出走"软惩罚"**：超容量不销毁东西，而是"堆在院子里的物资受潮/被偷（每天约 4%）"——温和压力，不是硬惩罚（挂机游戏最忌讳"回来发现产出全浪费"）。

### 背包：决定一次外出能带回多少

| 等级 | 名称 | 一次带回 | 材料 |
|---|---|---|---|
| 0 | 布兜 | 2~3 箱 | 开局自带 |
| 1 | 背篓 | 4~5 箱 | 木板×6 绳索×3 |
| 2 | 登山包 | 6~8 箱 | 皮革×4 绳索×5 木板×8 |
| 3 | 驮架 | 9~12 箱 | 皮革×8 铁块×10 绳索×8 |

在「工作台」面板升级（不占时段）。**背包越大，一次探索搬回的箱子越多。**

### 库存面板（可查看 / 整理）

- **分类页签**：材料 / 加工品 / 消耗品 / 装备 / 图纸 / 箱子
- **排序**：按数量 / 按阶段
- **操作**：逐项丢弃、装备穿脱与丢弃
- 每项显示 **阶层徽标（T1/T2/T3）** 与 **容量占用**
- 顶部显示储物箱等级与容量条（超容量变红）

| 手段 | 说明 | 何时有 |
|---|---|---|
| 资源点采集搜索 | 每小时概率出箱，箱子等级看地点危险度 | 开局 |
| **捕猎陷阱** | 消耗诱饵自动捕猎，**不占主角时段**，猎物常缠着箱子 | 造出陷阱后 |
| 探索周边 | 成批搬回（数量看背包），发现新地点与图纸 | 开局 |
| 天灾废墟 | 抗灾成功奖励（青铜箱起，后期白银箱） | 首灾后 |

### 箱子给什么（v7.3 重新分工）

**箱子不再承担建材供应，只给"顺手翻到的一点建材"——建材是采集的活。**

| 类别 | 占比 | 内容 |
|---|---|---|
| 装备 | 34% | 装备一件（品质按箱子等级） |
| 补给 | 33% | **口粮 / 水 / 生肉 / 诱饵**——这些只能靠箱子，是箱子的核心价值 |
| 材料 | 33% | 少量木/石/废金属 + 一个**稀有材料**（布料/兽皮/骨头/鳞片/铁块/矿石…） |

一箱材料约 **30 容量 ≈ 半天采集量**（树林一天 60 木材）。这样**采集和箱子各司其职**：建材靠采集，口粮水和稀有品靠箱子，谁也不碾压谁。

### 徒手配方（不用工作台）

有三样东西可以**徒手做**：**绳索、熏肉、诱饵**。

> 这不是可有可无的便利，而是**修掉了一个真实死锁**：工作台建造需要绳索（木材×100 + 石料×40 + 绳索×1），而绳索原本又必须用工作台造——两者互锁。如果玩家手里没有绳索（尤其是重生后物资清零、工作台没保留时），就会**永久卡死**。
>
> 现在绳索徒手可搓，起步链路永远是通的：**开箱拿兽皮 → 徒手搓绳 → 造工作台 → 解锁其余配方**。

## 装备：图纸带来的"时代跃迁"

**普通箱子给的是量变（石斧 +15/+18/+22）；图纸给的是质变（换时代 + 一条词条）。**

| 词条 | 效果 |
|---|---|
| 远程压制 | 野外遭遇野兽时 50% 概率全身而退 |
| 精良工具 | 采集产量 +25% |
| **照明** | **夜间也能出工——一天可用时段从 2 段变 3 段** |
| 抗性（保温/防水/防辐射/隔热/防酸） | 对应天灾强度视为 -30% |

**图纸机制**：探索 18% / 青铜箱 2% / 白银箱 5% / 黄金箱 12% / 遗迹箱 25% 掉落；
**未获得的图纸在面板上只显示「❓ 未知图纸」+ 一句传闻**，拿到才揭示——保留开箱的惊喜。

**装备代际与阶段挂钩**：阶段 1 只能造石制，阶段 2 解锁铁器与机械，阶段 3 才有火器与特化装备。

## ★ 威胁判定（挂机游戏的安全保险丝）

**核心原则：玩家永远不应该在不知情的情况下走进必死的局。**
挂机游戏的试错成本是"几天进度 + 一条命"，而且你不在场——所以"打一下试试"这个动作在结构上必须不存在。

### 五档判定（全游戏统一，同一套公式）

每个地点明码标出**威胁值**，与你的**战力**对比得出档位：

| 档位 | 条件 | 后果 | 遭遇概率 |
|---|---|---|---|
| ✅ 轻松 | 战力 ≥ 威胁 × 1.5 | 无伤，野兽远远躲着 | ×0.3 |
| ✅ 稳妥 | 战力 ≥ 威胁 × 1.1 | 偶有遭遇，稳赢 | ×0.6 |
| ⚠️ 吃力 | 战力 ≥ 威胁 × 0.8 | 可能受伤，**不会更糟** | ×1.0 |
| ⚠️ 危险 | 战力 ≥ 威胁 × 0.5 | 可能重伤，**自动止损** | ×1.2 |
| ⛔ **送死** | 战力 < 威胁 × 0.5 | **排班被拒绝**，下拉里直接禁用 | ×1.5 |

### 界面上会看到什么

```
📍 已发现地点（⚠️ 战力不够的地方去不了）
🦌 兽径                        ⛔ 送死
   威胁 90 ｜ 你 62 ｜ 生肉
   需要 120 战力才敢去
```

不只是"你不够"，而是**"差多少"**——总是给出明确的成长目标。

### 三道防线

1. **发现时提示**：探索出新地点时，日志当场说明威胁值与所需战力
2. **排班时拦截**：想把日程排到送死档地点 → 被拒绝并说明还差多少战力
3. **执行时兜底**：万一战力中途下降（卸下武器）导致计划变成送死档，主角会自动改成休息并说明原因

### 激进模式（想要更高收益就自己承担风险）

在「主角」面板可开启。开启后：
- 允许前往 ⛔ 送死档地点
- 在危险/送死档地点的产出 **+50%**
- **死亡只可能发生在这一档**（离线仍然免死）

这样死亡从"意外"变成了"决策"。

### 地点威胁一览

| 地点 | 威胁 | 什么时候能去 |
|---|---|---|
| 门口杂物堆 / 后山树林 / 上游河湾 | 1 | 开局就能去 |
| 碎石坡 | 2 | 开局就能去 |
| 旧加油站 | 30 | 需要一件像样的武器 |
| 露头煤层 | 40 | 阶段 2 |
| 铁矿洞 / 废弃超市 | 55 | 阶段 2 / 中期 |
| 铜矿脉 | 70 | 阶段 2 |
| 兽径 | 90 | 后期 |
| 硫磺坑 | 110 | 阶段 3 |
| 硝石床 | 130 | 阶段 3 |
| 废弃油田 | 150 | 阶段 3 |

> **远程压制词条**（连发弩/冲锋枪）在判定时视为**战力 +30%**——远程武器让你敢去更险的地方。
>
> 这套判定层将来会直接复用到**遗迹远征**与**怪物群**上（见设计文档 `2026-09-17 冒险判定与遗迹远征设计.md`）。

## 节奏设定（挂机流速）

**这是一款挂机（idle）游戏**——时间由 `tick()` 每秒自动推进，**不需要手动点"推进"**。你排好日程、设好流速，然后看着主角自己干活。

| 项 | 默认值 |
|---|---|
| 时间流速基准 | 现实 1 小时 ≈ 游戏 1 天（`TIME_SCALE = 24`） |
| 速档 | 顶栏 **1× / 2× / 4× / 8×**，默认 **2×**（现实 1 小时 ≈ 2 游戏天） |
| 挂机 3 小时（默认 2×） | ≈ 第 6 天，足以撑过第 3 天首灾 |
| 自动开箱 | 默认**开**：挂机时箱子即时打开，战利品直接进日志（关掉则箱子累积在「箱子」标签页手动开） |
| 挂机安全 | 角色自动吃喝不会饿死；天灾只损物资/降级不致死；切到后台按离线规则结算 |

> ⚠️ **历史坑**：早期 `TIME_SCALE = 3` 导致现实 3 小时只推进 0.37 天，玩家"挂机半天啥也没发生"——这是体感"活不下去"的真正根因，不是平衡问题。已提到 24 + 速档。

## 玩法要点

- **日程**：每天上午（6-12 时）、下午（12-18 时）各安排一件事——去某个资源点采集 / 探索周边 / 工作台加工 / 休息，夜间自动睡觉回体力
- **探索**：资源点靠「探索周边」发现，阶段推进后会有新地点进入待探索池
- **生存**：口粮和水每天消耗，**只能靠开箱和超市**获得；断粮会虚弱（效率减半）
- **体力**：采集消耗体力，连轴转会疲劳减产；伤势要靠休息或绷带
- **天灾**：第 3 天首灾，之后每 7 天一场，每场提前预告类型；防御不够会损失物资甚至跌回上一档房子
- **战力**：装备越好，野外遭遇越安全，能拿到的箱子品质也越高

## ★ 存档防回档：单写者裁决（v8.8）

**事故**：用户炼钢 30+ ×2 次后刷新回档——诊断确认是**两个游戏会话互相覆盖**（两个标签页/浏览器都开着，各自内存一份档轮流写库，历史快照里铁块/钢来回震荡为铁证）。

1. **服务端单写者裁决**：每次保存带会话标记（sid + 页面加载时间）。后打开/后刷新的标签页自动接管写入权；旧会话写入被 409 拒绝并自动停摆（防覆盖）；30 秒无写入视为会话死亡，任何页面可接管。同一会话刷新永远放行（sessionStorage 的 sid 不变）

3. **服务失败兜底**：数据库写入失败时立即写 localStorage（不再让进度只活在内存里）；下次加载时浏览器档与库"比新"，较新的自动迁回
4. 存档带 savedAt 时间戳，读取时双源比较

**规则**：只开一个游戏标签页玩；如果看到"⚠️ 游戏已在更新的标签页中打开"，说明另一页在写档——关掉旧页或刷新接管即可。

- **根因**：旧 `spotPos` 用 `if(x<330) x=660-x` 硬翻，被 clamp 的点都堆在 x=330 一条竖线上——而这条竖线恰好压到左侧外海的礁石上。
- **修法**：
  1. `tools/land-mask.py` 用 PIL 从底图抽像素（青蓝 = 海，棕/橄榄 = 陆），取**最大连通水体** (= 左侧外海) 当海，其余全算陆地（避免暗角/内陆水塘污染）。对每 16px 扫描线算"最右侧连续陆地段起点"存 `LAND_COAST`，**保证 `x ≥ coast ⇒ 必为陆地`**。
  2. `js/content/map.js` 新增 `landLeftX(y)` / `landLeftMax(y, span)` / `onLand(x, y, pad)` / `seaPath(pad)` 四个海岸线辅助函数；`spotPos` 改为四档吸附：①原位陆→直接落位 ②原位海→保持纬度向右滑到海岸线内侧（且距避难所 ≥ ring×0.85，保留"越远越危险"的视觉梯度） ③旋转 ±12° 最多 15 次 ④兜底贴岸。
  3. `onLand` 用 `landLeftMax(y, 48)` —— 上下 ±48px 取最保守值，让陡岸处的标记不会被边缘切掉。
- **配套工具**：
  - `tools/land-mask.py --dump` 输出 `tools/land-mask.json`（96×64 网格）+ 打印 `const LAND_COAST = [...]`。
  - `tools/land-check.js` headless 加载游戏模块，枚举所有 SPOTS 算 spotPos()，用 mask 圆盘（R=1 格）检测是否落海。`--dump` 额外输出 `tools/land-positions.json` 供叠图目检。
- **验证**：
  - 58 个地点全部落在陆地上（最近距海 2 格）；区域大字 3 个（幽能禁区/星尘荒原/虚空裂界）也全在陆地。
  - `tools/smoke-test.js` 319 项全过（含"同区域三点围绕避难所扩散"这一 v8.28 新断言）。
  - `tools/model-check.js` 15 组不变量全绿。
- **遗留说明**：海岸线采样步长 16px，相邻差最大值 160px（y=384~400 处海岸突入海 160px，由真实地貌决定，非算法误差）。

### v8.49（2026-09-20）修复局域网设备读不到存档（根因）
- 根因：`SERVER_MODE` 除 http 协议外还要求 `hostname === localhost/127.0.0.1`——从局域网另一台电脑用 `http://192.168.1.x:8787` 打开时被判成单机模式，无视数据库存档、只读该机浏览器 localStorage（表现为"打开就是新档"）。之前所有网络排查均正常，问题出在客户端这一行判定。
- 修法：`SERVER_MODE = (protocol 为 http/https)`；另加"比新"防回退——本地 localStorage 档想盖过数据库，除时间戳更新外还要求 `day ≥ 数据库 day`，防止换设备时残留的低进度新档顶掉高进度存档。
- smoke 322 项 + model-check 全绿。备份 `backups/2026-09-20_1958_多设备SERVER_MODE修复/`。
